# Luxe Estate Kolkata FAQ System

## What it is
A customer support FAQ system for Kolkata/West Bengal real estate regulatory queries.

## How to run
```bash
pip install -r requirements.txt
python3 main.py
# Opens at http://localhost:8000
```

## Test it
```bash
python3 evaluate.py
```

## What it covers
16 verified topics: home loans, stamp duty, WBHIRA, mutation, property tax, PMAY-U, SARFAESI, and more.

## Results
- 83.3% accuracy on 24 test cases
- 100% retrieval precision on in-scope queries
